# 药物相互作用预测：20 篇文献阅读记录

阅读口径：20 篇均核对 PubMed 题录与摘要；标记“全文相关章节”的文献，另阅读了公开全文相关方法或结果，或用户提供的原文。其余仅依据摘要，不能视为已经逐段通读全文。这里的结论均为作者研究内容的概述，不将论文自报的模型效果视为本研究的实验结果。

1. **OrganADR（2025）** — [PMID 40588546](https://pubmed.ncbi.nlm.nih.gov/40588546/)；摘要。融合器官、药物分子及生物医学网络信息，预测联合用药的器官层面不良反应；说明相互作用研究可以从事件分类扩展到受影响器官。与本项目的八类事件任务不同，不能直接比较指标。
2. **EmerGNN（2023）** — [PMID 38177736](https://pubmed.ncbi.nlm.nih.gov/38177736/)；摘要。利用生物医学网络中两个药物之间的路径，传播与预测有关的节点和边信息，面向缺乏已知相互作用的新药。与简单目标特征拼接的本项目方法不同。
3. **T-DDI（2026）** — [PMID 42477148](https://pubmed.ncbi.nlm.nih.gov/42477148/)；摘要，并核对[作者代码仓库](https://github.com/HienKha/tddi)。使用化学描述符、不确定性估计及特征解释进行多类 DDI 预测；作者提供了高置信度子集和新批准药物的案例。原文数据与本项目不同，其成绩不可直接比较。
4. **机器学习 DDI 研究综述（2026）** — [PMID 41611854](https://pubmed.ncbi.nlm.nih.gov/41611854/)；全文相关章节。梳理机器学习、图神经网络、数据来源、可解释性和临床应用，强调泛化与临床工作流整合仍是挑战。综述观点不等于任何一种模型已经实现临床验证。
5. **PK-DDIP（2022）** — [PMID 35817846](https://pubmed.ncbi.nlm.nih.gov/35817846/)；全文相关章节。由 FDA 说明书构建药代动力学相互作用数据，预测暴露量变化，并用后续说明书与患者数据进行外部评价。该连续量化任务与本项目事件分类不同。
6. **MHAFR-DDI（2026）** — [PMID 41729823](https://pubmed.ncbi.nlm.nih.gov/41729823/)；摘要。融合分子序列、二维结构和三维构象，结合预训练、对比学习及分层融合，评估长尾类别与冷启动；其交互图信息与本项目靶点指示特征并不等价。
7. **TRACE（2026）** — [PMID 41697921](https://pubmed.ncbi.nlm.nih.gov/41697921/)；全文相关章节。通过图 Transformer 结合元素知识和分子结构，报告分布内及分布外结果；[代码和数据](https://github.com/ZJUFanLab/TRACE)由作者公开。注意力可以帮助生成解释性假设，但不能独立证明机制。
8. **DDI 数据库与计算模型综述（2023）** — [PMID 38113076](https://pubmed.ncbi.nlm.nih.gov/38113076/)；全文相关章节。梳理数据库、网络服务与传统机器学习、深度学习和评分函数；为数据来源及分类问题定义提供背景。
9. **HetDDI（2023）** — [PMID 37903412](https://pubmed.ncbi.nlm.nih.gov/37903412/)；摘要。通过预训练异构图网络整合分子图和生物知识，考察二分类、多分类及多标签任务；不同任务和划分不应混为一谈。
10. **深度与图学习综合评价（2023）** — [PMID 37401373](https://pubmed.ncbi.nlm.nih.gov/37401373/)；摘要。概述结构、网络、文本及混合方法并进行比较，强调数据编码与评价设计影响模型比较。
11. **ACDGNN（2023）** — [PMID 37195815](https://pubmed.ncbi.nlm.nih.gov/37195815/)；摘要。以异构生物网络中的药物相关实体和跨域传播建模，评估传导式与归纳式设置，针对缺少既有 DDI 记录的药物。
12. **ProAlign-DDI（2026）** — [PMID 42906047](https://pubmed.ncbi.nlm.nih.gov/42906047/)；摘要。以语义原型对齐缓解长尾问题，研究未见过的 DDI 事件类别；其“未见类别”与本项目“未见药物”属于不同的泛化问题。
13. **IAMV-DDI（2026）** — [PMID 42670852](https://pubmed.ncbi.nlm.nih.gov/42670852/)；摘要。融合二维拓扑、三维几何和药物间交叉注意力，同时评估二分类与事件分类；与本项目简单特征拼接不可视为相同方法。
14. **FGSGT-DDI（2026）** — [PMID 42478169](https://pubmed.ncbi.nlm.nih.gov/42478169/)；摘要。提取官能团并使用大语言模型生成语义表示，与分子图特征融合，以研究多类别相互作用预测；不应把 LLM 生成的解释直接当作机制证据。
15. **BiG-Stack（2026）** — [PMID 42260929](https://pubmed.ncbi.nlm.nih.gov/42260929/)；摘要。结合分子指纹、靶点及生物特征，采用骨架不重叠的冷启动评价，并讨论上市后临床特征可能造成的泄漏。骨架划分比本研究按药物 ID 划分更严格。
16. **SMVSNN（2025）** — [PMID 40399143](https://pubmed.ncbi.nlm.nih.gov/40399143/)；摘要。针对抗肿瘤用药，采用多视角孪生脉冲神经网络与注意力融合，在其构建的数据集上进行五折验证。其结果不能直接证明乳腺癌患者疗效或本研究的模型性能。
17. **SF-Rx（2025）** — [PMID 40310752](https://pubmed.ncbi.nlm.nih.gov/40310752/)；摘要。结合结构相似性、PK/PD 特征，研究相互作用严重程度、类型与方向，并采用骨架划分及联邦学习。启示是明确预测终点与真实应用条件。
18. **机器学习 DDI 系统综述（2024）** — [PMID 38132638](https://pubmed.ncbi.nlm.nih.gov/38132638/)；摘要。总结数据库、化学与生物表征、浅层学习和深度学习，适合建立研究背景。
19. **CSK-DDI（2026）** — [PMID 42949104](https://pubmed.ncbi.nlm.nih.gov/42949104/)；用户提供原文相关章节及摘要。将分子 motif、分子图和知识图谱与交叉注意力结合，并讨论冷启动。本项目借鉴其问题设置，但没有实现或复现完整 CSK-DDI。
20. **DDI-Ben（2025）** — [PMID 41091924](https://pubmed.ncbi.nlm.nih.gov/41091924/)；全文相关章节。构建模拟药物分布变化的基准，报告多种方法在分布变化下的性能下降；[代码和数据](https://github.com/LARS-research/DDI-Bench)公开。本项目仅使用随机的药物 ID 留出，未实现该文的分布偏移模拟。

## 综合判断

多模态结构与生物知识、图学习、药代动力学量化、未见药物或类别的泛化，是文献中的重要方向。公开研究的任务定义、数据来源、划分和指标各不相同，不可把不同论文的数值直接排列为优劣。知识图谱、靶点或临床数据若在时间上晚于拟预测事件，也可能带来信息泄漏；可信评价需要时间切分、外部数据和针对性实验。
